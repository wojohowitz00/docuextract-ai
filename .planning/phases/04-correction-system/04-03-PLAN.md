  <files>backend/learning.py, backend/database.py, tests/test_learning.py</files>
  <action>
  1. Update `backend/database.py`:
     - Add table `learning_patterns`: `id`, `field_name`, `pattern_type` (exact/regex), `input_value`, `output_value`, `confidence`, `created_at`.
     - Add indexes for fast lookup.
     - Add CRUD functions for patterns.
  
  2. Create `backend/learning.py`:
     - `learn_from_correction(extraction_id, changes, db_conn)`:
       - Analyze changes to find patterns.
       - Simple rule: if `vendorName` changed, create mapping `original_value -> new_value`.
       - Store in `learning_patterns`.
     - `apply_patterns(extracted_data, db_conn)`:
       - Load relevant patterns.
       - Apply replacements to `extracted_data`.
       - Return modified data.
    
  3. Add `tests/test_learning.py`:
     - Test pattern creation from correction.
     - Test pattern application to new data.
  </action>
